생각 기준 금액은 상품 합계에서 쿠폰 할인을 뺀 값이고 배송비는 빠져요. 비율은 코드 상수가 아니라 정책 엔티티(DB) 값이에요. 이제 정리할게요.

기준 금액은 상품 금액 합계에서 쿠폰 할인을 뺀 금액이에요. 배송비와 이미 사용한 적립금은 기준 금액에 들어가지 않아요.

  • 상품 금액 합계: 주문에 담긴 상품 가격 × 수량을 모두 더한 값
  • 쿠폰 할인: 상품 쿠폰과 장바구니 쿠폰 할인액을 모두 뺀 뒤 계산
  • 사용 가능 비율: 코드에 고정된 값이 아니라 어드민에서 관리하는 적립금 정책 값이에요. 실제 비율은 어드민에서 확인해야 해요
val base = order.itemTotal - order.couponDiscount
val limit = (base * policy.usableRatio).setScale(0, RoundingMode.DOWN)
return minOf(limit, member.mileageBalance)

예를 들어 비율이 10%라면 상품 합계 50,000원에 쿠폰 5,000원을 쓸 때 기준 금액은 45,000원이고, 적립금은 최대 4,500원까지 쓸 수 있어요.
